# HoloDock

HoloDock is a free HoloSuite module for Foundry VTT that provides a system-agnostic ship loadout overview for sci-fi and vehicle-focused campaigns.

## Features

- Create and manage multiple ship profiles.
- Assign a custom ship image, with a bundled default ship image included.
- Add GM-defined ship statistics such as speed, fuel, defense, cargo, crew, or anything else your system needs.
- Create equipment slots with categories and descriptions.
- Drag regular Foundry Items onto equipment slots.
- Display equipped item names, icons, types, and item descriptions.
- Optionally place equipment pins directly on the ship image and draw link lines back to the relevant equipment slots.
- Open HoloDock from the HoloSuite launcher.

## Permissions

Players can view ship profiles and equipment loadouts from HoloSuite.

Only GMs can:

- create, edit, or delete ship profiles;
- change ship images;
- add, edit, or delete ship statistics;
- add, edit, or delete equipment slots;
- equip or remove items;
- place or clear ship-image equipment pins.

## Compatibility

- Minimum Foundry VTT version: 12
- Verified Foundry VTT version: 13
- Requires HoloSuite Core

## Release

Version 1.0.0 is the initial HoloDock release.
