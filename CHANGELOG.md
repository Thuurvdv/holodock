# Changelog

## 1.0.0 - 2026-07-08

- Initial HoloDock release for Foundry VTT v12 and v13.
- Added system-agnostic ship profiles with custom ship image support.
- Added GM-managed equipment slots with item drops, slot descriptions, and item descriptions.
- Added optional ship-image pin links from equipment slots to ship locations.
- Added customizable ship statistics for speed, fuel, defense, and other GM-defined values.
- Added HoloSuite Core launcher integration.
